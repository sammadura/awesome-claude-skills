# Awesome Claude Skills - Claude Development Guide

## Project Overview

A curated list of Claude Skills, resources, and tools for customizing Claude AI workflows. This repository serves as a community index and documentation hub for the Claude Skills ecosystem.

## Repository Structure

```
README.md           # Main curated list (the awesome-list)
CONTRIBUTING.md     # Contribution guidelines and quality standards
.claude/            # Claude Code configuration
  commands/         # Slash commands for maintaining the list
```

## Content Standards

### Adding New Skills
- Skills must provide clear value and be functional/tested
- Require social proof (generally 10+ GitHub stars)
- Include: name, repository link, 1-2 sentence description
- Categorize correctly (Official, Community, Tools, etc.)
- No promotional/SaaS wrappers or conversion funnels

### Quality Checks
- All links must be valid and point to active repositories
- Descriptions must be accurate and concise
- Formatting must follow the existing table/list patterns in README.md
- Categories must be alphabetically ordered within sections

## Editing Guidelines

- **README.md**: The main awesome-list. Follow existing formatting exactly.
- **CONTRIBUTING.md**: Contribution guidelines. Update when standards evolve.
- Preserve all badges, images, and HTML formatting in README.md header
- Keep descriptions to 1-2 sentences maximum
- Use consistent link formatting: `[name](url)` for inline, table format for skill lists

## Verification

Before claiming changes are complete:
- All markdown links are valid (no broken URLs)
- Formatting is consistent with existing entries
- Alphabetical ordering is maintained within categories
- No duplicate entries exist
