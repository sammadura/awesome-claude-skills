# Add Skill to Awesome List

Follow this process to add a new skill entry to README.md.

## Step 1: Gather Information
Ask for or verify the following:
- Skill name
- Repository URL
- Brief description (1-2 sentences)
- Category (Official, Community Collection, Individual Community Skill, Tool)

## Step 2: Validate
- Verify the repository exists and is accessible
- Check it meets quality standards (functional, documented, 10+ stars for community)
- Confirm no duplicate entry already exists in README.md
- Verify it's a genuine Claude Skill (has SKILL.md or equivalent)

## Step 3: Add Entry
- Find the correct category section in README.md
- Add the entry following the existing table/list format exactly
- Maintain alphabetical ordering within the category
- Use consistent formatting with other entries

## Step 4: Verify
- Confirm the markdown renders correctly
- Ensure no existing entries were accidentally modified
- Check alphabetical ordering is maintained
